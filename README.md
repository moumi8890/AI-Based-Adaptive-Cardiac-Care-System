 AI-Based Adaptive Cardiac Care System

 Project Overview
This project develops an AI-based software system that predicts cardiac risk and recommends personalized adaptive care pathways using Machine Learning and Explainable AI (XAI).

 Objectives
- Predict cardiac risk
- Recommend personalized care pathways
- Explain AI predictions
- Assist doctors in decision making
- Improve patient outcomes

 Technology Stack
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Machine Learning (Scikit-learn)
